# Enumerations

Typed constants for frame modes, themes, editor layouts, sort options and error codes. Use them in place of the raw string values they stand for.

## Overview

The following enumerations are available:

| Enum | Description |
| --- | --- |
| [`EditorType`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/javascript-sdk/usage-sdk/enumerations/EditorType.md) | The editor/viewer platform layout. |
| [`FilterSortBy`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/javascript-sdk/usage-sdk/enumerations/FilterSortBy.md) | The sort criterion for file/folder lists. |
| [`FilterSortOrder`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/javascript-sdk/usage-sdk/enumerations/FilterSortOrder.md) | The sort direction for file/folder lists. |
| [`HeaderBannerDisplaying`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/javascript-sdk/usage-sdk/enumerations/HeaderBannerDisplaying.md) | The header banner visibility. |
| [`ManagerViewMode`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/javascript-sdk/usage-sdk/enumerations/ManagerViewMode.md) | The item layout in [SDKMode.Manager](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/javascript-sdk/usage-sdk/enumerations/SDKMode.md#Manager) mode. |
| [`RoomType`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/javascript-sdk/usage-sdk/enumerations/RoomType.md) | Room types accepted by [SDKInstance.createRoom](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/javascript-sdk/usage-sdk/classes/SDKInstance.md#createroom) and returned as `roomType` in [TRoomInfo](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/javascript-sdk/usage-sdk/type-aliases/TRoomInfo.md) and [TSelectedRoom.roomType](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/javascript-sdk/usage-sdk/type-aliases/TSelectedRoom.md#roomType). |
| [`SDKErrorCode`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/javascript-sdk/usage-sdk/enumerations/SDKErrorCode.md) | Error codes for [SDKError](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/javascript-sdk/usage-sdk/classes/SDKError.md). |
| [`SDKMode`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/javascript-sdk/usage-sdk/enumerations/SDKMode.md) | The SDK initialization mode. |
| [`SelectorFilterType`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/javascript-sdk/usage-sdk/enumerations/SelectorFilterType.md) | The content filter for selector modes ([SDKMode.RoomSelector](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/javascript-sdk/usage-sdk/enumerations/SDKMode.md#RoomSelector), [SDKMode.FileSelector](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/javascript-sdk/usage-sdk/enumerations/SDKMode.md#FileSelector)). |
| [`Theme`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/javascript-sdk/usage-sdk/enumerations/Theme.md) | The UI color theme. |
