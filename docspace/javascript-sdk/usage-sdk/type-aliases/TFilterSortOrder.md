# TFilterSortOrder

String literal union of all [FilterSortOrder](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/javascript-sdk/usage-sdk/enumerations/FilterSortOrder.md) values.

Accepted by [TFrameFilter.sortOrder](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/javascript-sdk/usage-sdk/type-aliases/TFrameFilter.md#sortOrder).
Using the [FilterSortOrder](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/javascript-sdk/usage-sdk/enumerations/FilterSortOrder.md) enum constants is preferred.

```ts
type TFilterSortOrder = `${FilterSortOrder}`;
```
