# TEditorType

String literal union of all [EditorType](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/javascript-sdk/usage-sdk/enumerations/EditorType.md) values.

Accepted by [TFrameConfig.editorType](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/javascript-sdk/usage-sdk/type-aliases/TFrameConfig.md#editorType) and [TFrameConfig.type](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/javascript-sdk/usage-sdk/type-aliases/TFrameConfig.md#type).
Using the [EditorType](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/javascript-sdk/usage-sdk/enumerations/EditorType.md) enum constants is preferred.

```ts
type TEditorType = `${EditorType}`;
```
