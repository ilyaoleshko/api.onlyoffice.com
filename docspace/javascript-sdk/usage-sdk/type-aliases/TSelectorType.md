# TSelectorType

String literal union of all [SelectorFilterType](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/javascript-sdk/usage-sdk/enumerations/SelectorFilterType.md) values.

Accepted by [TFrameConfig.selectorType](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/javascript-sdk/usage-sdk/type-aliases/TFrameConfig.md#selectorType) in [SDKMode.FileSelector](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/javascript-sdk/usage-sdk/enumerations/SDKMode.md#FileSelector) mode.
Using the [SelectorFilterType](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/javascript-sdk/usage-sdk/enumerations/SelectorFilterType.md) enum constants is preferred.

```ts
type TSelectorType = `${SelectorFilterType}`;
```
