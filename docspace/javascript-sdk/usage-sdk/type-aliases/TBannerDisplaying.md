# TBannerDisplaying

String literal union of all [HeaderBannerDisplaying](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/javascript-sdk/usage-sdk/enumerations/HeaderBannerDisplaying.md) values.

Accepted by [TFrameConfig.showHeaderBanner](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/javascript-sdk/usage-sdk/type-aliases/TFrameConfig.md#showHeaderBanner).
Using the [HeaderBannerDisplaying](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/javascript-sdk/usage-sdk/enumerations/HeaderBannerDisplaying.md) enum constants is preferred.

```ts
type TBannerDisplaying = `${HeaderBannerDisplaying}`;
```
