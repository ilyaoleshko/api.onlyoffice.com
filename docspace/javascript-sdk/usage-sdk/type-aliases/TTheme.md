# TTheme

String literal union of all [Theme](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/javascript-sdk/usage-sdk/enumerations/Theme.md) values.

Accepted by [TFrameConfig.theme](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/javascript-sdk/usage-sdk/type-aliases/TFrameConfig.md#theme) to control the iframe color scheme.
Using the [Theme](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/javascript-sdk/usage-sdk/enumerations/Theme.md) enum constants is preferred.

```ts
type TTheme = `${Theme}`;
```
