# TFilterSortBy

String literal union of all [FilterSortBy](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/javascript-sdk/usage-sdk/enumerations/FilterSortBy.md) values.

Accepted by [TFrameFilter.sortBy](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/javascript-sdk/usage-sdk/type-aliases/TFrameFilter.md#sortBy).
Using the [FilterSortBy](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/javascript-sdk/usage-sdk/enumerations/FilterSortBy.md) enum constants is preferred.

```ts
type TFilterSortBy = `${FilterSortBy}`;
```
