# CSPApiUrl

The ONLYOFFICE Apps CSP validation endpoint. Used internally to check
whether the current host domain is allowed in the target ONLYOFFICE Apps instance.

```ts
const CSPApiUrl: "/api/2.0/security/csp";
```

## See

[TFrameConfig.checkCSP](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/javascript-sdk/usage-sdk/type-aliases/TFrameConfig.md#checkCSP) — enables/disables CSP validation on frame init.
