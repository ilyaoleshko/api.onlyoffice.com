# HeaderBannerDisplaying

The header banner visibility. Passed via [TFrameConfig.showHeaderBanner](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/javascript-sdk/usage-sdk/type-aliases/TFrameConfig.md#showHeaderBanner).

## Enumeration Members

<APITable>

| Enumeration Member | Value | Description |
| ------ | ------ | ------ |
| `All` | `"all"` | Show all banners (informational + promotional). |
| `Info` | `"info"` | Show only informational banners. |
| `None` | `"none"` | Hide all banners. |

</APITable>
