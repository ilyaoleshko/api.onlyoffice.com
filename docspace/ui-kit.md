# UI Kit

`@onlyoffice/apps-ui-kit` is the React component library every ONLYOFFICE Apps product is built with, and the UI a DocSpace plugin renders its screens in. Start with **Getting started** for the two providers and the import forms, then pick a component by what it does.

The reference is organised into these sections:

| Section | Description |
| --- | --- |
| [Getting started](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/getting-started.md) | What the kit is, how to install it, and the pieces every application sets up once: the theme and translation providers, the API client, and the hooks, utilities and constants the components share. |
| [Components](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/components.md) | The composites built from the UI components for the portal's screens. |
| [UI](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui.md) | The components themselves, grouped by what they do on a page: controls, overlays, data display, navigation, feedback and layout. |
