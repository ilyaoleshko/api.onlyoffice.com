# Selectors

The portal's pickers: a panel that lists files, rooms, people, groups, AI agents or MCP servers from a portal and hands back what the user chose.

## Overview

The following components are available:

| Component | Description |
| --- | --- |
| [AIAgentSelector](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/components/selectors/aiagentselector.md) | AIAgentSelector is a selector panel for choosing an AI agent room. |
| [FilesSelector](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/components/selectors/filesselector.md) | FilesSelector is a full file-system browser selector for navigating ONLYOFFICE Apps rooms, folders, and files. |
| [GroupsSelector](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/components/selectors/groupsselector.md) | GroupsSelector is a searchable, paginated selector panel for choosing a user group. |
| [MCPServersSelector](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/components/selectors/mcpserversselector.md) | MCPServersSelector is a multi-select panel for choosing available MCP (Model Context Protocol) servers to connect to an AI agent. |
| [PeopleSelector](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/components/selectors/peopleselector.md) | PeopleSelector is a searchable, paginated selector for choosing users and groups from the ONLYOFFICE Apps system. |
| [RoomSelector](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/components/selectors/roomselector.md) | RoomSelector is a searchable, paginated selector for choosing rooms from the ONLYOFFICE Apps system. |
