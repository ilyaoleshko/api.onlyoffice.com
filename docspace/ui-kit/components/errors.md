# Errors

The full-page states the portal shows when a request fails: access denied, not found, offline, unavailable, an expired link.

## Overview

The following components are available:

| Page | Description |
| --- | --- |
| [AccessRestricted](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/components/errors/accessrestricted.md) | Access restricted error page. |
| [Error401](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/components/errors/error401.md) | Unauthorized error page (401). |
| [Error403](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/components/errors/error403.md) | Forbidden error page (403). |
| [Error404](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/components/errors/error404.md) | Not Found error page (404). |
| [ErrorInvalidLink](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/components/errors/errorinvalidlink.md) | Invalid link error page. |
| [ErrorOffline](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/components/errors/erroroffline.md) | Offline error page. |
| [ErrorUnavailable](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/components/errors/errorunavailable.md) | Unavailable error page. |
