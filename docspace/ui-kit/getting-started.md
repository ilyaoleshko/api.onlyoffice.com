# Getting started

What the kit is, how to install it, and the pieces every application sets up once: the theme and translation providers, the API client, and the hooks, utilities and constants the components share.

The following pages are available:

| [Agent skills](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/getting-started/agent-skills.md) | The `ui-kit` skill teaches an AI coding agent to build screens with this kit in your own React app: which component fits the job, what its props are called, how to install and theme it, and a check it runs on the result. |

| [Constants](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/getting-started/constants.md) | Three small modules carry the values and the vocabulary the rest of the library is written in. |
