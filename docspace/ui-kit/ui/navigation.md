# Navigation

Links, tabs, paging and the side menu that moves the user between views.

## Overview

The following components are available:

| Component | Description |
| --- | --- |
| [`Filter`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/navigation/filter.md) | The bar above a file listing: search, a filter panel, a sort menu, a view switch and the chips for what is in force. |
| [`Link`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/navigation/link.md) | Anchor styled to the kit's conventions, for navigation or for an in-place action. |
| [`NavMenu`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/navigation/nav-menu.md) | Sidebar navigation: groups of items, each with an optional sub-menu, a badge and a collapsed rail form. |
| [`Navigation`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/navigation/navigation-component.md) | The file manager's header: breadcrumb title, back arrow, and the row of buttons that acts on the current folder. |
| [`Paging`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/navigation/paging.md) | Previous and next buttons with a page selector between them and a page-size selector at the end. |
| [`TabItem`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/navigation/tab-item.md) | Rounded pill that fills in when it is selected. |
| [`Tabs`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/navigation/tabs.md) | Sticky tab bar that scrolls sideways and renders the selected tab's content under itself. |
| [`TwoStateToggle`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/navigation/two-state-toggle.md) | Pill that switches the portal between its classic view and the new dashboard. |
