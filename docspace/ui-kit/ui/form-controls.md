# Form controls

Inputs, pickers and the containers that label them. Every control here is controlled: it renders the value it is given and reports changes through its callback.

## Overview

The following components are available:

| Component | Description |
| --- | --- |
| [`AccessRightSelect`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/form-controls/access-right-select.md) | Drop-down for choosing an access level, with an icon, a description and a paid badge on each row. |
| [`Calendar`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/form-controls/calendar.md) | Month grid for picking a day, with month and year views behind it. |
| [`Checkbox`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/form-controls/checkbox.md) | Checkbox with a label, an indeterminate state and an optional help button. |
| [`ColorInput`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/form-controls/color-input.md) | Hex field with a swatch that opens a colour picker. |
| [`ColorPicker`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/form-controls/color-picker.md) | Saturation square with a hue strip for choosing a colour, with or without a hex field and buttons. |
| [`ComboBox`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/form-controls/combobox.md) | Button showing the current choice, with a list of options under it. |
| [`DatePicker`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/form-controls/date-picker.md) | Button that becomes a removable chip once a date is chosen, with a calendar behind it. |
| [`DateTimePicker`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/form-controls/date-time-picker.md) | A date chip and a time beside it, editable in place. |
| [`EmailInput`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/form-controls/email-input.md) | Text field that parses what is typed as an email address and colours itself when it does not parse. |
| [`FieldContainer`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/form-controls/field-container.md) | Layout wrapper for one form field: an optional label with a help tooltip, the control itself, and its error message. |
| [`FileInput`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/form-controls/file-input.md) | Read-only field with a folder icon that opens the file dialog and accepts a drop. |
| [`FormWrapper`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/form-controls/form-wrapper.md) | White card of a fixed width that the portal's sign-in and wizard forms sit on. |
| [`InputBlock`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/form-controls/input-block.md) | Text field with an icon at the end and room for a prefix before it, inside one border. |
| [`Label`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/form-controls/label.md) | Caption for a form field, with an optional required asterisk and an error colour. |
| [`PasswordInput`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/form-controls/password-input.md) | Password field with a reveal eye, a strength tooltip and a generator. |
| [`QuantityPicker`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/form-controls/quantity-picker.md) | Minus and plus around a number, with an optional slider and quick-add chips. |
| [`RadioButtonGroup`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/form-controls/radio-button-group.md) | A set of radio buttons built from an array, with the selected value handled for you. |
| [`RadioButton`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/form-controls/radio-button.md) | One option of a single-choice set, drawn as a labelled circle. |
| [`SearchInput`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/form-controls/search-input.md) | Search field with a magnifier, an optional clear button and a debounced change callback. |
| [`Slider`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/form-controls/slider.md) | Range input with the kit's own track and handle. |
| [`TextInput`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/form-controls/text-input.md) | Controlled single-line text field in three fixed widths, with optional masking, error and warning states. |
| [`Textarea`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/form-controls/textarea.md) | Multi-line text field that grows with its content, with optional line numbers, a copy button and a JSON mode. |
| [`TimePicker`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/form-controls/time-picker.md) | Two small fields, hours and minutes, that move the caret along as you type. |
| [`ToggleButton`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/form-controls/toggle-button.md) | Switch for one on/off setting, with an optional label beside it. |
