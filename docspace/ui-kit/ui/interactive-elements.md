# Interactive elements

Buttons in their variants -- plain, icon, floating, main-menu -- and the drag-and-drop surfaces: components whose job is to be clicked or dragged.

## Overview

The following components are available:

| Component | Description |
| --- | --- |
| [`ActionButton`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/interactive-elements/action-button.md) | Small tinted button for a secondary action, optionally rendered as another element. |
| [`AddButton`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/interactive-elements/add-button.md) | Square icon button with an optional label beside it, for adding one more of something. |
| [`Button`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/interactive-elements/button.md) | Labelled action button with an optional icon, a loading state and a tooltip, in a primary or secondary variant. |
| [`ContextMenuButton`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/interactive-elements/context-menu-button.md) | Icon that opens a menu of actions, built afresh from a callback each time it is clicked. |
| [`DragAndDrop`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/interactive-elements/drag-and-drop.md) | Wrapper that turns whatever is inside it into a drop target for files, with no interface of its own. |
| [`Dropzone`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/interactive-elements/dropzone.md) | Dashed upload area with a picture, a prompt and a format list, which turns into a loader while the upload runs. |
| [`FloatingButton`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/interactive-elements/floating-button.md) | Round corner badge that shows the progress of a background operation and opens its panel. |
| [`HelpButton`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/interactive-elements/help-button.md) | Info icon that opens an explanation on click, for a label that needs more than a label. |
| [`IconButton`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/interactive-elements/icon-button.md) | Icon that acts as a button, with hover and pressed colours and an optional tooltip. |
| [`ImageEditor`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/interactive-elements/image-editor.md) | Crop window with drag, zoom and a replace control, for turning an uploaded picture into an avatar or a logo. |
| [`LinkWithDropdown`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/interactive-elements/link-with-dropdown.md) | Dashed link that opens a menu under itself. |
| [`MainButtonMobile`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/interactive-elements/main-button-mobile.md) | Floating round button in the corner of the screen that opens a full-width sheet of actions. |
| [`MainButton`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/interactive-elements/main-button.md) | Accent button at the top of a side menu that opens a menu of the things a user can create. |
