# Status components

Loaders and progress: spinners, the full-screen application loader, the infinite-scroll loader and the progress bar.

## Overview

The following components are available:

| Component | Description |
| --- | --- |
| [`AppLoader`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/status-components/app-loader.md) | The blank first screen: a fixed sheet over the whole viewport with the kit's rombs animation on it. |
| [`InfiniteLoader`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/status-components/infinite-loader.md) | Virtualised list or grid that asks for the next page as the user scrolls towards the end. |
| [`LoaderWrapper`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/status-components/loader-wrapper.md) | Dims whatever is inside it and stops the mouse reaching it while something is loading. |
| [`Loader`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/status-components/loader.md) | Spinner in one of four animations, for work whose duration is unknown. |
| [`ProgressBar`](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/status-components/progress-bar.md) | A labelled bar for an operation whose progress you can measure, with a status or error line under it. |
