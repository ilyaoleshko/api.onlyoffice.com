# UI

The components themselves, grouped by what they do on a page: controls, overlays, data display, navigation, feedback and layout.

## Overview

The groups are:

| Group | Description |
| --- | --- |
| [Form controls](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/form-controls.md) | Inputs, pickers and the containers that label them. |
| [Interactive elements](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/interactive-elements.md) | Buttons in their variants -- plain, icon, floating, main-menu -- and the drag-and-drop surfaces: components whose job is to be clicked or dragged. |
| [Status components](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/status-components.md) | Loaders and progress: spinners, the full-screen application loader, the infinite-scroll loader and the progress bar. |
| [Layout](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/layout.md) | The page's plumbing: portals, scroll areas, the selection rectangle and the theme wrapper. |
| [Layout components](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/layout-components.md) | Screens for the moments a view has nothing to show: an empty folder, a search with no results, an error. |
| [Overlays](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/overlays.md) | Everything drawn above the page: modal dialogs and side panels, drop-downs and context menus, tooltips and the selector. |
| [Data display](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/data-display.md) | Components that show a value rather than take one: text and headings, avatars, badges and tags, room icons and logos, and cards. |
| [Skeletons](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/skeletons.md) | Placeholder shapes shown while content loads, so the layout does not jump when it arrives. |
| [Feedback](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/feedback.md) | Components that tell the user what happened or what is happening: toasts and snack bars, status messages, info bars and progress for long operations. |
| [Navigation](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/navigation.md) | Links, tabs, paging and the side menu that moves the user between views. |
| [Rows](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/rows.md) | The row-based list the portal shows files and rooms in, with its container and content layout. |
| [Table](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/table.md) | The data table with resizable columns, its header, rows and group menu. |
| [Tiles](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/ui-kit/ui/tiles.md) | The tile grid: a container, the base tile and the file, folder, room and template tiles built on it. |
