# Changelog

The list of changes for ONLYOFFICE DocSpace Plugins SDK.

## Version 2.0

- Separated file security into a new `FilesSecurity` enum.
- Added the `fileSecurity` and `security` properties to [IFileItem](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/plugins-sdk/usage-sdk/coding-plugin/interfaces/items/IFileItem.md).
- Added the `withoutBodyPadding` and `withoutHeaderMargin` properties to [IModalDialog](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/plugins-sdk/usage-sdk/coding-plugin/interfaces/components/IModalDialog.md).
- Added the `updateCreateDialogModal` action to [Actions](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/plugins-sdk/usage-sdk/coding-plugin/enums/Actions.md).
- Added the `isAutoFocusOnError`, `errorText`, `onError`, `onChange`, `isCloseAfterCreate`, and `isCreateDisabled` properties to [ICreateDialog](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/plugins-sdk/usage-sdk/coding-plugin/interfaces/components/ICreateDialog.md).
- Added the `itemSecurity` property to [IContextMenuItem](https://ilyaoleshko.github.io/api.onlyoffice.com/docspace/plugins-sdk/usage-sdk/coding-plugin/interfaces/items/IContextMenuItem.md).
