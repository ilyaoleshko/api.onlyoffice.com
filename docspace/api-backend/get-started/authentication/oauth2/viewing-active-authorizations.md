# Viewing active authorizations

Each user can see the applications they have granted access to on the profile page, on the **Authorized apps** tab.

![Authorized apps](https://ilyaoleshko.github.io/assets/images/docspace/authorized-apps.png#gh-light-mode-only)![Authorized apps](https://ilyaoleshko.github.io/assets/images/docspace/authorized-apps.dark.png#gh-dark-mode-only)

To revoke access rights from the specified application, click ![More icon](https://ilyaoleshko.github.io/assets/images/docspace/more-icon.png#gh-light-mode-only)![More icon](https://ilyaoleshko.github.io/assets/images/docspace/more-icon.dark.png#gh-dark-mode-only) to open the context menu and press the **Revoke** button.

![Revoke app rights](https://ilyaoleshko.github.io/assets/images/docspace/revoke.png#gh-light-mode-only)![Revoke app rights](https://ilyaoleshko.github.io/assets/images/docspace/revoke.dark.png#gh-dark-mode-only)
