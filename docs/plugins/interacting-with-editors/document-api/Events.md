# Events

| Event | Description |
| ----- | ----------- |

| [onBlurContentControl](https://ilyaoleshko.github.io/api.onlyoffice.com/docs/plugins/interacting-with-editors/document-api/Events/onBlurContentControl.md) | The function called to show which content control has been blurred. |
| [onChangeCommentData](https://ilyaoleshko.github.io/api.onlyoffice.com/docs/plugins/interacting-with-editors/document-api/Events/onChangeCommentData.md) | The function called when the specified comment is changed with the [ChangeComment](https://ilyaoleshko.github.io/api.onlyoffice.com/docs/plugins/interacting-with-editors/document-api/Methods/ChangeComment.md) method. |
| [onChangeContentControl](https://ilyaoleshko.github.io/api.onlyoffice.com/docs/plugins/interacting-with-editors/document-api/Events/onChangeContentControl.md) | The function called to show which content control has been changed. |
| [onChangeCurrentPage](https://ilyaoleshko.github.io/api.onlyoffice.com/docs/plugins/interacting-with-editors/document-api/Events/onChangeCurrentPage.md) | The function called when the current page has changed. |
| [onChangeRestrictions](https://ilyaoleshko.github.io/api.onlyoffice.com/docs/plugins/interacting-with-editors/document-api/Events/onChangeRestrictions.md) | The function called when the restrictions in the editor are changed. |
| [onClick](https://ilyaoleshko.github.io/api.onlyoffice.com/docs/plugins/interacting-with-editors/document-api/Events/onClick.md) | The function called when the user clicks the element. |
| [onClickAnnotation](https://ilyaoleshko.github.io/api.onlyoffice.com/docs/plugins/interacting-with-editors/document-api/Events/onClickAnnotation.md) | The function called when the user clicks an annotation. |
| [onDocumentContentReady](https://ilyaoleshko.github.io/api.onlyoffice.com/docs/plugins/interacting-with-editors/document-api/Events/onDocumentContentReady.md) | The function called when the document is completely loaded. |
| [onEnableMouseEvent](https://ilyaoleshko.github.io/api.onlyoffice.com/docs/plugins/interacting-with-editors/document-api/Events/onEnableMouseEvent.md) | The function called to turn the mouse or touchpad events on/off. |
| [onExternalMouseUp](https://ilyaoleshko.github.io/api.onlyoffice.com/docs/plugins/interacting-with-editors/document-api/Events/onExternalMouseUp.md) | The function called when the mouse button is released outside the plugin iframe. |
| [onFocusAnnotation](https://ilyaoleshko.github.io/api.onlyoffice.com/docs/plugins/interacting-with-editors/document-api/Events/onFocusAnnotation.md) | The function called when an annotation receives focus. |
| [onFocusContentControl](https://ilyaoleshko.github.io/api.onlyoffice.com/docs/plugins/interacting-with-editors/document-api/Events/onFocusContentControl.md) | The function called to show which content control has been focused. |
| [onHideContentControlTrack](https://ilyaoleshko.github.io/api.onlyoffice.com/docs/plugins/interacting-with-editors/document-api/Events/onHideContentControlTrack.md) | The function called when the content control loses focus in the document. |
| [onInsertOleObjects](https://ilyaoleshko.github.io/api.onlyoffice.com/docs/plugins/interacting-with-editors/document-api/Events/onInsertOleObjects.md) | The function called when one or more OLE objects are inserted into the document. |
| [onParagraphText](https://ilyaoleshko.github.io/api.onlyoffice.com/docs/plugins/interacting-with-editors/document-api/Events/onParagraphText.md) | The function called when the paragraph text is updated in the document. |
| [onRemoveComment](https://ilyaoleshko.github.io/api.onlyoffice.com/docs/plugins/interacting-with-editors/document-api/Events/onRemoveComment.md) | The function called when the specified comment is removed with the [RemoveComments](https://ilyaoleshko.github.io/api.onlyoffice.com/docs/plugins/interacting-with-editors/document-api/Methods/RemoveComments.md) method. |
| [onShowContentControlTrack](https://ilyaoleshko.github.io/api.onlyoffice.com/docs/plugins/interacting-with-editors/document-api/Events/onShowContentControlTrack.md) | The function called when the content control receives focus and its track appears. |
| [onSubmitForm](https://ilyaoleshko.github.io/api.onlyoffice.com/docs/plugins/interacting-with-editors/document-api/Events/onSubmitForm.md) | The function called when the user clicks the "Complete & Submit" button. |
| [onTargetPositionChanged](https://ilyaoleshko.github.io/api.onlyoffice.com/docs/plugins/interacting-with-editors/document-api/Events/onTargetPositionChanged.md) | The function called when the target position in the editor is changed. |
