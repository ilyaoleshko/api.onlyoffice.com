# Events

| Event | Description |
| ----- | ----------- |
| [onChangeCurrentSlide](https://ilyaoleshko.github.io/api.onlyoffice.com/docs/plugins/interacting-with-editors/presentation-api/Events/onChangeCurrentSlide.md) | The function called when the current slide has changed. |
| [onChangeRestrictions](https://ilyaoleshko.github.io/api.onlyoffice.com/docs/plugins/interacting-with-editors/presentation-api/Events/onChangeRestrictions.md) | The function called when the restrictions in the editor are changed. |
| [onClick](https://ilyaoleshko.github.io/api.onlyoffice.com/docs/plugins/interacting-with-editors/presentation-api/Events/onClick.md) | The function called when the user clicks the element. |
| [onDocumentContentReady](https://ilyaoleshko.github.io/api.onlyoffice.com/docs/plugins/interacting-with-editors/presentation-api/Events/onDocumentContentReady.md) | The function called when the document is completely loaded. |
| [onEnableMouseEvent](https://ilyaoleshko.github.io/api.onlyoffice.com/docs/plugins/interacting-with-editors/presentation-api/Events/onEnableMouseEvent.md) | The function called to turn the mouse or touchpad events on/off. |
| [onExternalMouseUp](https://ilyaoleshko.github.io/api.onlyoffice.com/docs/plugins/interacting-with-editors/presentation-api/Events/onExternalMouseUp.md) | The function called when the mouse button is released outside the plugin iframe. |
| [onSlideShowBegin](https://ilyaoleshko.github.io/api.onlyoffice.com/docs/plugins/interacting-with-editors/presentation-api/Events/onSlideShowBegin.md) | The function called when a slide show presentation starts. |
| [onSlideShowEnd](https://ilyaoleshko.github.io/api.onlyoffice.com/docs/plugins/interacting-with-editors/presentation-api/Events/onSlideShowEnd.md) | The function called when a slide show presentation ends. |
| [onSlideShowNextSlide](https://ilyaoleshko.github.io/api.onlyoffice.com/docs/plugins/interacting-with-editors/presentation-api/Events/onSlideShowNextSlide.md) | The function called after a slide has been changed and displayed during a slide show presentation. Fires before the slide content is actually displayed. |
| [onSlideShowSlideChanged](https://ilyaoleshko.github.io/api.onlyoffice.com/docs/plugins/interacting-with-editors/presentation-api/Events/onSlideShowSlideChanged.md) | The function called when slide changes during a slide show presentation. Provides information about both the current and previous slide. |
| [onTargetPositionChanged](https://ilyaoleshko.github.io/api.onlyoffice.com/docs/plugins/interacting-with-editors/presentation-api/Events/onTargetPositionChanged.md) | The function called when the target position in the editor is changed. |
