# Events

| Event | Description |
| ----- | ----------- |
| [onChangeCurrentSheet](https://ilyaoleshko.github.io/api.onlyoffice.com/docs/plugins/interacting-with-editors/spreadsheet-api/Events/onChangeCurrentSheet.md) | The function called when the current sheet has changed. |
| [onChangeRestrictions](https://ilyaoleshko.github.io/api.onlyoffice.com/docs/plugins/interacting-with-editors/spreadsheet-api/Events/onChangeRestrictions.md) | The function called when the restrictions in the editor are changed. |
| [onClick](https://ilyaoleshko.github.io/api.onlyoffice.com/docs/plugins/interacting-with-editors/spreadsheet-api/Events/onClick.md) | The function called when the user clicks the element. |
| [onDocumentContentReady](https://ilyaoleshko.github.io/api.onlyoffice.com/docs/plugins/interacting-with-editors/spreadsheet-api/Events/onDocumentContentReady.md) | The function called when the document is completely loaded. |
| [onEnableMouseEvent](https://ilyaoleshko.github.io/api.onlyoffice.com/docs/plugins/interacting-with-editors/spreadsheet-api/Events/onEnableMouseEvent.md) | The function called to turn the mouse or touchpad events on/off. |
| [onExternalMouseUp](https://ilyaoleshko.github.io/api.onlyoffice.com/docs/plugins/interacting-with-editors/spreadsheet-api/Events/onExternalMouseUp.md) | The function called when the mouse button is released outside the plugin iframe. |
| [onTargetPositionChanged](https://ilyaoleshko.github.io/api.onlyoffice.com/docs/plugins/interacting-with-editors/spreadsheet-api/Events/onTargetPositionChanged.md) | The function called when the target position in the editor is changed. |
