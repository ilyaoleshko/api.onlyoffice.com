# Screens

The cabinet's screens, in the order a client meets them.

## Overview

The screens are:

| Screen | Description |
| --- | --- |
| [01. My matters](./my-matters.md) | The first screen anyone at the firm opens, and the first one a client opens: the matters that are theirs. |
| [02. Inside a matter](./inside-a-matter.md) | The screen the whole track exists for. |
| [03. Sending a document](./sending-a-document.md) | The client's one job: hand over what the firm asked for. |
| [04. Reading the firm's draft](./reading-the-firm-s-draft.md) | The other half of the exchange. |
| [05. Opening a matter](./opening-a-matter.md) | The lawyer's side of the whole track in one form. |
