# Samples

Applications built from the kit against a portal: a client cabinet for a law firm, held through a whole track of screens, and a small Files app.

## Overview

The samples are:

| Sample | Description |
| --- | --- |
| [Legal practice](./legal-practice/index.md) | A client cabinet for a law firm: one problem held through the whole track, each screen a question and the components that answer it. |
| [A small Files app](./a-small-files-app.md) | A Files application on one screen: the rooms, the personal folder and the trash in the sidebar; folders opened in place, with a breadcrumb back; search, a type filter and a sort order; rows or tiles; a selection toolbar; new folders and documents, renames and deletes; uploads; files opened in ONLYOFFICE. |
