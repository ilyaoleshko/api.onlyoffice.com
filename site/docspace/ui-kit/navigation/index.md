# Navigation

Links, tabs, paging and the side menu that moves the user between views.

## Overview

The following components are available:

| Component | Description |
| --- | --- |
| [`Link`](./link.md) | Anchor styled to the kit's conventions, for navigation or for an in-place action. |
| [`NavMenu`](./nav-menu.md) | Sidebar navigation: groups of items, each with an optional sub-menu, a badge and a collapsed rail form. |
| [`Paging`](./paging.md) | Previous and next buttons with a page selector between them and a page-size selector at the end. |
| [`TabItem`](./tab-item.md) | Rounded pill that fills in when it is selected. |
| [`Tabs`](./tabs.md) | Sticky tab bar that scrolls sideways and renders the selected tab's content under itself. |
